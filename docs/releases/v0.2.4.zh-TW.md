## 版本摘要

Local GitHub Library 0.2.4 集中完善「我的收藏」工作流程。現在可以為收藏專案保存本機備註、集中匯出備註，並透過目錄列內圖示完成重新命名和刪除；同時把本機大型模型改為跨版本重複使用的獨立發佈，避免每個程式版本重複上傳模型。

## 主要更新

- 收藏專案新增備註功能，可新增、查看、修改和刪除，最多保存 4000 個字元。
- 可將所有非空收藏備註匯出為帶時間戳的 UTF-8 TXT 檔案。
- 收藏備註保存在本機 `favorites.json`，會隨 `.ghconfig` 設定包一起匯入和匯出。
- 「收藏目錄」標題右側新增加號按鈕，用於建立目錄。
- 每個目錄列新增重新命名和刪除圖示，目錄名稱、倉庫數量和操作圖示保持一致居中。
- 刪除目錄前會顯示確認提示；目錄中的本機收藏專案和備註會一併刪除。
- 大型模型改用獨立的 `models-qwen2.5-1.5b-v1` 預發佈提供，程式版本不再重複上傳 `.ghllm` 或完整離線包。

## 問題修正

- 修正恢復預設版面按鈕與工作區標籤未垂直置中的問題。
- 統一收藏目錄列的目錄名稱、倉庫數量、重新命名和刪除圖示的垂直中心。
- 重新命名圖示採用無外層底板的「方框+鉛筆」向量圖形，並適配淺色和深色主題。

## 相容性與升級

- 從 0.2.3 升級不需要遷移收藏、備註、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 刪除收藏目錄只影響本機資料，而且無法復原。
- 基礎搜尋、榜單、收藏和報告功能不需要本機模型；需要 AI 摘要與翻譯時，請從獨立的 LLM 模型庫下載並匯入模型。

## 平台與限制

- Windows 10/11 x64。
- 程式為自包含發佈，不要求預先安裝 .NET。
- 搜尋、目前榜單和 README 讀取需要存取 GitHub。
- 本機 LLM 為可選的獨立下載，不包含在 0.2.4 標準包中。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。
