## Summary

Local GitHub Library 0.2.7 focuses on favorite organization and application settings. Users can enable Windows startup, identify noted projects directly in the directory list, and customize repository order with a long-press drag. Dragging now uses a translucent ghost that follows the pointer and an eased row-sliding animation. My Favorites opens on Directory Contents by default.

## Highlights

- Add “开机时自动启动 Local GitHub Library” to app settings, disabled by default.
- Register Windows startup under the current user's `Run` key without administrator privileges.
- Show a clickable note icon before repositories with notes; unmarked repositories show no icon.
- Long-press a repository name for 300 ms to enter drag mode, with a clear cursor and drag ghost.
- Reorder rows continuously across the list while dragging, using a 180 ms eased slide animation.
- Persist custom order in `favorites.json` through the `SortOrder` field.
- Keep newly favorited repositories at the top of the directory.
- Place Directory Contents before Search Results and select it by default in My Favorites.
- Automatically switch to Search Results after a search completes.

## Fixes

- Replace the previous Windows OLE drag implementation that could fail to start dragging.
- Fix drag-ghost text being rendered outside the floating card.
- Preserve the Windows-startup setting when the close-behavior setting is updated.

## Compatibility and upgrade

- Upgrading from 0.2.6 requires no migration of favorites, notes, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- Existing favorites without `SortOrder` continue in saved-date order until the first manual drag writes an explicit order.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- Windows startup is scoped to the current user and refreshes the executable path on the next launch after the app is moved.
- The local LLM remains an optional separate download and is not included in the 0.2.7 standard package.

## Platforms and limitations

- Windows 10/11 x64.
- Self-contained executable; a separate .NET installation is not required.
- Favorite dragging changes order only within the current folder, not between folders.
- Search, current rankings, and README reading require GitHub access.
- The unsigned executable may trigger a Windows SmartScreen warning.
- The repository does not currently declare an open-source license.
