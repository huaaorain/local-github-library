## 版本摘要

Local GitHub Library 0.2.5 新增集中式软件设置和系统托盘工作流。常用工具从顶部收起，关闭窗口时可以选择最小化到托盘或完全退出，并能决定是否每次都询问。现有搜索、榜单、收藏、报告和独立模型发布方式保持不变。

## 主要更新

- 顶部新增齿轮按钮，集中提供导入 LLM、导入配置、导出配置和打开文档库。
- 关闭窗口时可选择最小化到系统托盘或完全退出程序。
- 可在软件设置中固定默认关闭行为，并选择是否每次关闭都询问。
- 关闭确认窗口也提供“每次关闭窗口时都询问我”选项；取消勾选后会记住本次选择。
- 托盘图标支持双击恢复主窗口，以及右键打开主窗口或完全退出。
- 软件设置保存在 `GitHubReports/Data/app-settings.json`，并随 `.ghconfig` 配置包导入导出。
- 顶部只保留深色/浅色模式与齿轮按钮，并移除按钮组外层的圆角容器。

## 问题修复

- 修复关闭确认窗口中“完全退出程序”和“取消”按钮可能重叠的问题。
- 调整关闭确认窗口底部操作区，使取消按钮稳定位于右下角。
- 避免关闭事件重入，确保选择退出后能正常结束程序。

## 兼容性与升级

- 从 0.2.4 升级不需要迁移收藏、备注、报告、Star 快照、提示词、榜单缓存或 `.ghconfig` 数据。
- 首次运行 0.2.5 时，默认启用关闭询问；未选择时会提示最小化到托盘或完全退出。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 本地 LLM 仍是可选独立下载，不包含在 0.2.5 标准包中。

## 平台与限制

- Windows 10/11 x64。
- 程序为自包含发布，不要求预装 .NET。
- 系统托盘依赖 Windows 通知区域。
- 搜索、当前榜单和 README 读取需要访问 GitHub。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 当前仓库尚未声明开源许可证。

- 托盘最小化、恢复窗口和默认退出分支测试通过。
