## Summary

Local GitHub Library 0.3.1 improves favorite-folder organization and window layout continuity. Favorite folders can now be reordered by long-press drag in both directory lists, with the order saved locally. Panel widths for all three workspaces, the main window size, and maximized state are saved on close and restored on the next launch.

## Highlights

- Reorder folders with a 300 ms long press in both the Search workspace directory list and the My Favorites directory list.
- Show a translucent drag ghost that follows the pointer and animate affected rows with eased motion.
- Persist folder order through the `SortOrder` field in `favorites.json`.
- Save the left and right panel widths independently for My Favorites, Search, and Rankings.
- Save the main window width, height, and maximized state.
- Save the resulting layout when Reset Layout is used.

## Fixes

- Fix the previous binding that enabled dragging only in the My Favorites list while the visible Search-workspace directory list could not be dragged.
- Preserve the new layout fields when save settings or close behavior updates app settings.

## Compatibility and upgrade

- Upgrading from 0.3.0 requires no migration of favorites, notes, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- Older `app-settings.json` files without layout fields automatically receive the default window size and panel widths.
- Configuration exports include layout settings but still exclude GitHub Tokens.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- The local LLM remains an optional separate download and is not included in the 0.3.1 standard package.

## Platforms and limitations

- Windows 10/11 x64.
- Window position is not persisted across launches; only size and maximized state are restored.
- Only the left and right panel widths are stored; the center panel remains adaptive.
- The unsigned executable may trigger a Windows SmartScreen warning.
- The repository does not currently declare an open-source license.

## Verification

- Release build passes with zero warnings and zero errors.
- Drag reordering, the 300 ms threshold, and order persistence pass for both directory lists.
- Layout loading and saving pass for all workspace widths, window size, and settings persistence.
- Existing search, reports, favorites, settings, sorting, tray, and compact-layout tests pass.
