## 版本摘要

Local GitHub Library 0.2.5 新增集中式軟體設定和系統托盤工作流程。常用工具從頂部收起，關閉視窗時可以選擇最小化到托盤或完全結束，並能決定是否每次都詢問。現有搜尋、榜單、收藏、報告和獨立模型發佈方式保持不變。

## 主要更新

- 頂部新增齒輪按鈕，集中提供匯入 LLM、匯入設定、匯出設定和開啟文件庫。
- 關閉視窗時可選擇最小化到系統托盤或完全結束程式。
- 可在軟體設定中固定預設關閉行為，並選擇是否每次關閉都詢問。
- 關閉確認視窗也提供「每次關閉視窗時都詢問我」選項；取消勾選後會記住本次選擇。
- 托盤圖示支援雙擊恢復主視窗，以及右鍵開啟主視窗或完全結束。
- 軟體設定保存在 `GitHubReports/Data/app-settings.json`，並隨 `.ghconfig` 設定包匯入匯出。
- 頂部只保留深色/淺色模式與齒輪按鈕，並移除按鈕組外層的圓角容器。

## 問題修正

- 修正關閉確認視窗中「完全結束程式」和「取消」按鈕可能重疊的問題。
- 調整關閉確認視窗底部操作區，使取消按鈕穩定位於右下角。
- 避免關閉事件重入，確保選擇結束後能正常關閉程式。

## 相容性與升級

- 從 0.2.4 升級不需要遷移收藏、備註、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 首次執行 0.2.5 時，預設啟用關閉詢問；未選擇時會提示最小化到托盤或完全結束。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 本機 LLM 仍是可選獨立下載，不包含在 0.2.5 標準包中。

## 平台與限制

- Windows 10/11 x64。
- 程式為自包含發佈，不要求預先安裝 .NET。
- 系統托盤依賴 Windows 通知區域。
- 搜尋、目前榜單和 README 讀取需要存取 GitHub。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。

## 驗證結果

- 軟體設定的預設值、保存與重新載入測試通過。
- 軟體設定隨 `.ghconfig` 匯出和匯入的測試通過。
- 托盤最小化、恢復視窗和預設結束分支測試通過。
- 設定視窗、關閉確認視窗、收藏介面、排序和緊湊版面測試通過。
