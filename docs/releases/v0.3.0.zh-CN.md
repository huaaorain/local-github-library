## 版本摘要

Local GitHub Library 0.3.0 新增 GitHub 账号登录与私有仓库搜索。用户可以在软件设置中使用 Personal Access Token 验证并保存登录状态，随后搜索当前账号有权限访问的公开和私有仓库。登录凭据使用 Windows DPAPI 加密，仅对当前 Windows 用户可用，且不会写入报告或 `.ghconfig` 配置包。

## 主要更新

- 软件设置新增“GitHub 账号”区域，可验证 Token、显示当前登录账号并退出登录。
- GitHub 认证信息统一用于仓库搜索、README 读取和项目详情请求。
- 登录后可搜索账号拥有权限的私有仓库，包括组织仓库和协作者仓库。
- 由于 GitHub 自带的仓库搜索索引可能遗漏私有仓库或私有 Fork，程序会额外读取账号可访问的仓库清单，在本地按关键词匹配并去重后合并结果。
- Token 使用 Windows DPAPI 按当前用户加密保存在 `GitHubReports/Data/github-auth.bin`。
- 配置导出明确排除登录凭据；退出登录会删除本机保存的 Token。
- 首页新增 Fine-grained Personal Access Token 创建步骤、权限建议、官方链接和安全说明。

## 问题修复

- 修复仅使用匿名 GitHub API 时无法返回个人私有仓库的问题。
- 修复私有仓库因 GitHub 搜索索引覆盖不足而无法通过关键词找到的问题。
- 更新原有环境变量和 `github-token.txt` 兼容提示，引导新用户使用软件内登录流程。

## 兼容性与升级

- 从 0.2.7 升级不需要迁移收藏、备注、报告、Star 快照、提示词、榜单缓存或 `.ghconfig` 数据。
- 原有 `GITHUB_TOKEN` 环境变量和 `github-token.txt` 仍可作为高级配置方式使用。
- 配置文件导入不包含 GitHub 登录凭据，每台电脑需单独登录。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 本地 LLM 仍是可选独立下载，不包含在 0.3.0 标准包中。

## 平台与限制

- Windows 10/11 x64。
- 程序为自包含发布，不要求预装 .NET。
- 私有仓库搜索需要 Token 对相应仓库具有 `Metadata` 与 `Contents` 的只读权限。
- 为弥补搜索索引遗漏，登录后额外匹配最近更新的最多 1,000 个可访问仓库。
- 组织可能要求管理员批准 Fine-grained Token。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 当前仓库尚未声明开源许可证。
