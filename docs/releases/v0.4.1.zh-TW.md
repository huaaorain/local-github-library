## 版本摘要

Local GitHub Library 0.4.1 新增可自訂的全域呼出快速鍵、表格欄寬記憶與更可靠的安裝層級開機啟動註冊，同時把授權條款明確為 PolyForm Noncommercial 1.0.0。

## 主要更新

- 新增全域呼出快速鍵，預設 `Ctrl+Shift+D`；視窗最小化到工作列或系統托盤後可快速還原。
- 快速鍵可在軟體設定中重新錄製、恢復預設並保存，重新啟動軟體後繼續生效。
- 表格欄寬現在會隨工作區版面一起保存；搜尋、總榜和收藏中的表格會在重新啟動後恢復上次寬度。
- 顯示中的表格欄邊界就是拖動區域，不再額外繪製第二條直線，也不會出現重複分隔線或色差。
- 開機啟動項目改為依安裝目錄產生獨立註冊名稱；同一台電腦上的不同程式副本不會互相刪除啟動項目。
- 新增 PolyForm Noncommercial 1.0.0 標準授權條款，並將其加入標準包和獨立程式發佈附件。

## 問題修正

- 修正舊版通用開機啟動項目可能被另一個程式副本重複使用的問題。
- 修正調整表格欄寬後重新啟動即恢復預設的問題。
- 修正快速鍵修改後需要重新啟動才能還原視窗的問題。
- 修正系統托盤或工作列最小化狀態下缺少快速還原入口的問題。

## 相容性與升級

- 從 0.4.0 升級不需要遷移報告、收藏、備註、筆記、Star 快照、提示詞或榜單快取。
- 如果舊設定中沒有快速鍵或表格欄寬欄位，程式會自動使用預設值。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 本機 LLM 仍是可選獨立下載，不包含在本版本標準包中。
- 授權變更不影響此前已發佈版本的授權狀態；從 0.4.1 起，新版本採用非商業授權。

## 平台與限制

- Windows 10/11 x64。
- 全域快速鍵必須包含至少一個修飾鍵，並可能與其他軟體占用的組合衝突。
- GitHub 搜尋和榜單需要網路；收藏瀏覽、已快取榜單和本機筆記可離線使用。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 本專案採用 PolyForm Noncommercial 1.0.0，僅允許非商業用途；它不是 OSI 開源授權。商業用途需要另行取得授權。

- Release 建置通過。

- 從工作列和系統托盤還原視窗驗證通過。
