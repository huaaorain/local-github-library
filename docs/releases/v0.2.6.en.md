## Summary

Local GitHub Library 0.2.6 adds typo-tolerant search and a new multi-resolution application icon. When exact results are sparse, the app corrects one or two English characters using a local technical vocabulary and performs one bounded fallback query. Original exact matches always stay ahead of fallback results. Search, rankings, favorites, reports, and the separate model-release strategy remain unchanged.

## Highlights

- Correct mistyped English terms with missing, extra, substituted, or transposed characters.
- Correct long queries token by token, such as `machine learnign` to `machine learning`.
- Preserve exact results first and issue only one additional corrected query when needed.
- Avoid automatic replacement for terms of three characters or fewer, protecting short acronyms such as `jev`.
- Include a built-in technical vocabulary and learn new terms from result Topics and repository names.
- Persist learned terms in the local `search-vocabulary.txt` file so they remain available after restart.
- Show `original → corrected` in the search UI and indicate that spelling correction was used.
- Apply one multi-resolution icon to the EXE, window title bars, Windows taskbar, and notification tray.

## Fixes

- Fix searches returning no results after a single mistyped or extra character.
- Fix local whole-term filtering discarding every candidate under minor spelling differences.

## Compatibility and upgrade

- Upgrading from 0.2.5 requires no migration of favorites, notes, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- The search vocabulary is a local auxiliary cache and is not uploaded to third-party services.
- The local LLM remains an optional separate download and is not included in the 0.2.6 standard package.

## Platforms and limitations

- Windows 10/11 x64.
- Self-contained executable; a separate .NET installation is not required.
- Search, current rankings, and README reading require GitHub access.
- A very niche technical term that has never been learned may still receive no automatic correction.
- The unsigned executable may trigger a Windows SmartScreen warning.
- The repository does not currently declare an open-source license.
