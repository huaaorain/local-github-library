## 版本摘要

Local GitHub Library 0.4.0 新增完整的本地笔记工作区，并把笔记存储升级为按目录层级组织的 Markdown 与图片仓库。笔记支持目录树、拖动排序、正文图片、加粗、文字颜色、自动保存、加密和右键操作；同时加入单实例保护、原子写入、索引备份和损坏检测，避免再次出现索引与正文被写坏的问题。

## 主要更新

- 在“查找”“总榜”“收藏”之外新增“笔记”工作区。
- 使用目录树组织笔记，支持新建目录、删除目录和长按拖动排序。
- 每条笔记保存为同名 `.md` 文件，相关图片保存在同级 `images` 目录。
- 支持正文内粘贴图片、复制原图、Ctrl+滚轮缩放和正文内图片持久化。
- 支持加粗、六种文字颜色及 `Ctrl+S` 保存。
- 保留每 3 分钟自动保存，并在未保存退出时询问。
- 支持右键打开、保存、移动、删除、新建目录、新建笔记和“打开方式”。
- “打开方式”支持默认程序、记事本、Visual Studio Code 和资源管理器。
- 加密笔记使用 PBKDF2-SHA256 + AES-GCM；加密正文和图片分别保存为 `.md.enc` 与 `*.png.enc`。
- 删除加密笔记时必须再次输入正确密码。
- `.ghconfig` 会包含普通笔记、目录层级、图片、加密笔记和富文本元数据。

## 问题修复

- 修复不同目录深度下笔记删除图标参差不齐的问题。
- 修复正文粘贴后字体、粗细和颜色混杂的问题。
- 修复加密笔记图片在重新打开后显示为 Markdown 文本的问题。
- 修复密码窗口底部按钮被裁切的问题。
- 修复同一目录笔记拖动时缺少平滑让位动画的问题。
- 修复不同层级笔记全部堆积在最低层级目录下方的问题。
- 新增单实例运行限制，避免多个程序同时写入笔记数据。
- 索引、Markdown、图片和加密文件改为校验后原子写入，并保留索引 `.bak` 备份。
- 主索引损坏时自动尝试读取备份；数据仍不可读时停止写入并显示明确错误。

## 兼容性与升级

- 从 0.3.1 升级不需要重新导入报告、收藏、备注、Star 快照、提示词或榜单缓存。
- 旧版普通笔记会在首次加载时迁移为目录、Markdown 和图片文件。
- 旧版加密笔记无法在不知道密码时读取标题，会先生成安全占位目录；解锁并保存后自动改为真实笔记名称。
- 笔记文件格式发生较大变化。升级前建议先导出 `.ghconfig` 或复制整个 `GitHubReports` 目录。
- 从旧版升级时请只运行一个程序实例。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 本地 LLM 仍是可选独立下载，不包含在本版本标准包中。

## 平台与限制

- Windows 10/11 x64。
- 加密笔记会保护正文与图片内容；标题、目录名和文件数量可能仍能从本地路径看出。
- 忘记笔记密码后无法恢复正文。
- 笔记工作区支持离线使用；GitHub 搜索和榜单仍需要联网。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 当前仓库尚未声明开源许可证。
