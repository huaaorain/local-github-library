## 版本摘要

Local GitHub Library 0.2.3 是应用级界面设计与交互状态版本。本次重构保持搜索、榜单、收藏、报告和本地 LLM 的业务行为不变，集中改善信息层级、组件一致性、键盘操作、深浅色主题和小窗口适配。

## 主要更新

- 建立应用设计规范，统一语义颜色、字体层级、4/8 间距、圆角和交互状态。
- 重构顶部工具区、工作区标签导航、查询工具条、三栏工作区和状态栏。
- 新增浅色与深色主题；启动时跟随 Windows 应用主题，也可从顶部即时切换。
- 统一按钮、输入框、下拉框、标签页、列表、表格、滚动条和空状态样式。
- 增加悬停、按下、禁用、键盘焦点和高对比焦点环。
- 表格可排序表头增加手型光标、悬停/按下反馈以及升序/降序箭头。
- 仓库名、描述和目录名使用省略号时提供完整内容提示。
- 紧凑窗口最低支持 `980 × 620`，LLM 设置窗口最低支持 `620 × 520`。

## 问题修复

- 表格所有列的正文统一为相同字号和字体，并保持垂直居中。
- 修复语言、时间等列内容偏上的问题。
- 标签栏、查询工具条和三栏工作区使用一致的左右边界。
- 恢复默认布局按钮已移动到标签栏垂直中心。
- 修复表格表头可点击但没有明显反馈的问题。
- 改善空收藏目录、空查询记录和空总榜记录状态。

## 兼容性与升级

- 从 0.2.2 升级不需要迁移收藏、报告、Star 快照、提示词、榜单缓存或 `.ghconfig` 数据。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 主题切换不会修改查询、收藏或报告数据。
- 手动选择的主题仅在当前运行期间生效；重新启动后再次跟随 Windows 应用主题。

## 平台与限制

- Windows 10/11 x64。
- 程序为自包含发布，不要求预装 .NET。
- 搜索、当前榜单和 README 读取需要访问 GitHub。
- 本地 LLM 为可选功能；标准包不含模型，完整包包含 Qwen2.5 1.5B。
- 当前仓库尚未声明开源许可证。

## 验证结果

- 浅色和深色主题资源、切换按钮、下拉模板与焦点属性测试通过。
- 表格列统一对齐、排序反馈、紧凑布局和恢复布局测试通过。
- 收藏、提示词、README 提取、报告、历史和配置测试通过。
- 浅色与深色主要文字对比度均高于 WCAG AA 的 4.5:1。
