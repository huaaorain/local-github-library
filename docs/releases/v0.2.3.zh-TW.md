## 版本摘要

Local GitHub Library 0.2.3 是應用程式級介面設計與互動狀態版本。本次重構保持搜尋、榜單、收藏、報告和本機 LLM 的業務行為不變，集中改善資訊層級、元件一致性、鍵盤操作、深淺色主題和小視窗適配。

## 主要更新

- 建立應用設計規範，統一語意顏色、字體層級、4/8 間距、圓角和互動狀態。
- 重構頂部工具區、工作區標籤導覽、查詢工具列、三欄工作區和狀態列。
- 新增淺色與深色主題；啟動時跟隨 Windows 應用程式主題，也可從頂部即時切換。
- 統一按鈕、輸入框、下拉選單、標籤頁、清單、表格、捲軸和空狀態樣式。
- 增加懸停、按下、停用、鍵盤焦點和高對比焦點環。
- 表格可排序表頭增加手型游標、懸停/按下回饋以及升序/降序箭頭。
- 倉庫名稱、描述和目錄名稱使用省略號時提供完整內容提示。
- 緊湊視窗最低支援 `980 × 620`，LLM 設定視窗最低支援 `620 × 520`。

## 問題修正

- 表格所有欄位的正文統一為相同字號和字體，並保持垂直置中。
- 修正語言、時間等欄位內容偏上的問題。
- 標籤列、查詢工具列和三欄工作區使用一致的左右邊界。
- 恢復預設版面按鈕已移動到標籤列垂直中心。
- 修正表格表頭可點擊但沒有明顯回饋的問題。
- 改善空收藏目錄、空查詢記錄和空總榜記錄狀態。

## 相容性與升級

- 從 0.2.2 升級不需要遷移收藏、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 主題切換不會修改查詢、收藏或報告資料。
- 手動選擇的主題僅在目前執行期間生效；重新啟動後再次跟隨 Windows 應用程式主題。

## 平台與限制

- Windows 10/11 x64。
- 程式為自包含發佈，不要求預先安裝 .NET。
- 搜尋、目前榜單和 README 讀取需要存取 GitHub。
- 本機 LLM 為可選功能；標準包不含模型，完整包包含 Qwen2.5 1.5B。
- 目前倉庫尚未宣告開源授權。

## 驗證結果

- 淺色和深色主題資源、切換按鈕、下拉模板與焦點屬性測試通過。
- 表格欄位統一對齊、排序回饋、緊湊版面和恢復版面測試通過。
- 收藏、提示詞、README 擷取、報告、歷史和設定測試通過。
- 淺色與深色主要文字對比度均高於 WCAG AA 的 4.5:1。
