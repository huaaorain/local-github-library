## 版本摘要

Local GitHub Library 0.3.1 改進收藏目錄組織和視窗版面體驗。收藏目錄現在可以在左右兩個目錄清單中長按拖動排序，順序會保存在本機；三個工作區的面板寬度、主視窗尺寸和最大化狀態也會在關閉時保存，並在下次啟動時還原。

## 主要更新

- 「搜尋專案」左側目錄清單和「我的收藏」目錄清單均支援長按 300 ms 後拖動排序。
- 目錄拖動時顯示跟隨滑鼠的半透明虛影，並對受影響的列使用緩動動畫。
- 目錄順序寫入 `favorites.json` 的 `SortOrder` 欄位，重新啟動後保持。
- 分別保存「我的收藏」「搜尋專案」「總榜」三個工作區的左右面板寬度。
- 保存主視窗寬度、高度和最大化狀態。
- 點擊「恢復預設版面」會同時保存新的預設版面。

## 問題修正

- 修正上一版只為「我的收藏」頁目錄清單綁定拖動事件，實際「搜尋專案」左側目錄清單無法拖動的問題。
- 修正軟體設定和關閉行為保存時可能覆寫新增版面欄位的問題。

## 相容性與升級

- 從 0.3.0 升級不需要遷移收藏、備註、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 舊版 `app-settings.json` 沒有版面欄位時會自動使用預設視窗尺寸和面板寬度。
- 設定匯出會包含版面設定，但不會包含 GitHub Token。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 本機 LLM 仍是可選獨立下載，不包含在 0.3.1 標準包中。

## 平台與限制

- Windows 10/11 x64。
- 視窗位置不會跨啟動保存；僅保存尺寸和最大化狀態。
- 面板寬度只保存左右兩欄，中間欄保持自適應。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。
