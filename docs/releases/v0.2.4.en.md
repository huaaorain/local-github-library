## Summary

Local GitHub Library 0.2.4 focuses on the Favorites workflow. Favorited repositories can now have persistent local notes, notes can be exported together, and inline directory actions support rename and deletion. Local LLM packages are also published independently so application releases no longer upload the same large model every time.

## Highlights

- Add, view, edit, and delete a local note for each favorited repository, up to 4,000 characters.
- Export all non-empty favorite notes to a timestamped UTF-8 TXT file.
- Store notes in the local `favorites.json` file so they travel with `.ghconfig` imports and exports.
- Add a plus button beside the “收藏目录” heading for creating a folder.
- Add inline rename and delete controls to every folder row while keeping the folder name, repository count, and action icons aligned.
- Confirm before deleting a folder; its locally saved repositories and notes are removed with it.
- Publish the LLM through the separate `models-qwen2.5-1.5b-v1` pre-release rather than duplicating `.ghllm` and full offline packages in every application version.

## Fixes

- Center the layout reset control vertically with the workspace tabs.
- Align the folder name, repository count, rename control, and delete control on the same row centerline.
- Redraw the rename control as a borderless vector icon that adapts to the light and dark themes.

## Compatibility and upgrade

- Upgrading from 0.2.3 requires no migration of favorites, notes, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- Folder deletion affects local data only and cannot be undone.
- Search, rankings, favorites, and reports do not require the local model. Download and import it from the separate LLM model library only when AI summaries and translations are needed.

## Platforms and limitations

- Windows 10/11 x64.
- Self-contained executable; a separate .NET installation is not required.
- Search, current rankings, and README reading require GitHub access.
- The local LLM is an optional separate download and is not included in the 0.2.4 standard package.
- The unsigned executable may trigger a Windows SmartScreen warning.
- The repository does not currently declare an open-source license.
