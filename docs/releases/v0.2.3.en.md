## Summary

Local GitHub Library 0.2.3 is an application-wide interface design and interaction-state release. Search, rankings, favorites, reports, and the optional local LLM retain their existing behavior while information hierarchy, component consistency, keyboard use, light/dark themes, and compact-window behavior are substantially improved.

## Highlights

- Added an application design specification covering semantic color, typography, 4/8 spacing, radii, and interaction states.
- Reworked the header utilities, workspace tabs, query command bars, three-pane workspace, and status bar.
- Added light and dark themes, following the Windows application theme at launch with an immediate header switch.
- Unified buttons, inputs, selectors, tabs, lists, tables, scrollbars, and empty states.
- Added hover, pressed, disabled, keyboard-focus, and high-contrast focus-ring states.
- Sortable table headers now show a hand cursor, hover/pressed feedback, and ascending or descending arrows.
- Ellipsized repository names, descriptions, and directory names expose their complete value through tooltips.
- Compact windows are supported down to `980 × 620`; the LLM settings dialog supports `620 × 520`.

## Fixes

- All table columns now use the same body font and size with consistent vertical centering.
- Fixed language and timestamp cells appearing too close to the top edge.
- Aligned the tab bar, query command bar, and three workspace panes to the same horizontal boundaries.
- Centered the reset-layout button vertically in the workspace tab bar.
- Added visible feedback to clickable table headers.
- Improved empty states for folders, query history, and global-ranking history.

## Compatibility and upgrade

- Upgrading from 0.2.2 requires no migration of favorites, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- Theme switching does not modify queries, favorites, or reports.
- A manual theme selection applies for the current run; the next launch follows the Windows application theme again.

## Platforms and limitations

- Windows 10/11 x64.
- Self-contained executable; a separate .NET installation is not required.
- Search, current rankings, and README reading require GitHub access.
- The local LLM is optional. The standard package omits the model; the full package includes Qwen2.5 1.5B.
- The repository does not currently declare an open-source license.

## Verification

- Light/dark theme resources, the theme switch, selector templates, and focus properties passed automated tests.
- Table alignment, sorting feedback, compact layout, and layout restoration passed automated tests.
- Favorites, prompts, README extraction, reports, history, and configuration tests passed.
- Primary text contrast in both themes exceeds the WCAG AA 4.5:1 threshold.
