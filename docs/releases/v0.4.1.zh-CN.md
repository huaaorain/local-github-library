## 版本摘要

Local GitHub Library 0.4.1 新增可自定义的全局呼出快捷键、表格列宽记忆和更可靠的安装级开机启动注册，同时把许可证明确为 PolyForm Noncommercial 1.0.0。

## 主要更新

- 新增全局呼出快捷键，默认 `Ctrl+Shift+D`；窗口最小化到任务栏或系统托盘后可快速恢复。
- 快捷键可在软件设置中重新录入、恢复默认并保存，重启软件后继续生效。
- 表格列宽现在会随工作区布局一起保存；查找、总榜和收藏中的表格在重启后恢复上次宽度。
- 显示中的表格列边界就是拖动区域，不再额外绘制第二条竖线，也不会出现重复分隔线或色差。
- 开机启动项改为按安装目录生成独立注册名；同一台电脑上的不同程序副本不会互相删除启动项。
- 新增 PolyForm Noncommercial 1.0.0 标准许可证文本，并将其加入标准包和独立程序发布附件。

## 问题修复

- 修复旧版通用开机启动项可能被另一个程序副本复用的问题。
- 修复调整表格列宽后重启即恢复默认的问题。
- 修复快捷键修改后需要重启才能恢复窗口的问题。
- 修复系统托盘或任务栏最小化状态下缺少快速恢复入口的问题。

## 兼容性与升级

- 从 0.4.0 升级不需要迁移报告、收藏、备注、笔记、Star 快照、提示词或榜单缓存。
- 如果旧配置中没有快捷键或表格列宽字段，程序会自动使用默认值。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 本地 LLM 仍是可选独立下载，不包含在本版本标准包中。
- 许可证变更不影响此前已经发布版本的授权状态；从 0.4.1 起，新版本采用非商业许可证。

## 平台与限制

- Windows 10/11 x64。
- 全局快捷键必须包含至少一个修饰键，并可能与其他软件占用的组合冲突。
- GitHub 搜索和榜单需要联网；收藏浏览、已缓存榜单和本地笔记可离线使用。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 本项目采用 PolyForm Noncommercial 1.0.0，仅允许非商业用途；它不是 OSI 开源许可证。商业用途需要单独授权。
