# Local GitHub Library 0.2.1

0.2.1 是界面布局与发布质量补丁，不改变本地数据格式。

## 新增

- 三个主工作区支持拖动左右面板调整宽度。
- 标签栏右上角新增紧凑的圆角三横线按钮，可恢复默认布局。
- 标题栏与工作区之间增加轻微渐变分隔带。
- 应用标题与标签栏之间增加水平分隔线。

## 优化

- 面板边框重新显示，并与中间拖动线保留更宽间距。
- 拖动线默认灰色，仅在按住或拖动期间变黑，松开后立即恢复。
- 重置布局按钮不会与标签或工作区内容重合。

## 兼容性

- 从 0.2.0 升级不需要迁移收藏、报告、提示词或模型包。
- 发布包仍为 Windows 10/11 x64，并保留 `runtimes` 目录要求。
- 完整离线包包含 Qwen2.5 1.5B 模型；标准包需要时另行导入 `.ghllm`。
