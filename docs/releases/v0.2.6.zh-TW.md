## 版本摘要

Local GitHub Library 0.2.6 新增錯字容錯搜尋，並啟用新的多解析度應用程式圖示。精確結果不足時，程式會使用本機技術詞庫修正 1–2 個英文字元後再查詢一次；原有精確結果始終優先。搜尋、榜單、收藏、報告和獨立模型發佈方式保持不變。

## 主要更新

- 新增英文關鍵字拼寫修正，支援漏字、多字、錯字和相鄰字母顛倒。
- 支援多詞逐詞修正，例如 `machine learnign` 會按 `machine learning` 嘗試搜尋。
- 原始精確結果始終排在前；只有結果不足時才增加一次修正查詢。
- 三位以內的縮寫不會自動替換，避免誤改 `jev` 等短關鍵字。
- 內建常見技術詞庫，並從搜尋結果的 Topics 和倉庫名稱中持續學習新詞。
- 學到的技術詞保存在本機 `search-vocabulary.txt`，重新啟動後仍可使用。
- 搜尋介面會顯示 `原始關鍵字 → 修正關鍵字`，並提示已啟用拼寫修正。
- EXE、視窗標題列、Windows 工作列和系統托盤統一使用新的多解析度應用程式圖示。

## 問題修正

- 修正輸入一個字母錯誤或多餘字母時搜尋結果直接為零的問題。
- 修正本機整詞過濾在輕微拼寫偏差下過濾全部候選的問題。

## 相容性與升級

- 從 0.2.5 升級不需要遷移收藏、備註、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 搜尋詞庫是本機輔助快取，不會上傳到第三方服務。
- 本機 LLM 仍是可選獨立下載，不包含在 0.2.6 標準包中。

## 平台與限制

- Windows 10/11 x64。
- 程式為自包含發佈，不要求預先安裝 .NET。
- 搜尋、目前榜單和 README 讀取需要存取 GitHub。
- 首次搜尋非常冷門且尚未收錄的技術詞時，自動修正可能無法給出候選。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。

## 驗證結果

- `unitty → unity`、`pythno → python`、`kubernets → kubernetes` 測試通過。
- 多詞逐詞修正和三字母短詞保護測試通過。
- 本機技術詞庫學習與重新載入測試通過。
- UI、收藏、排序、設定、托盤和緊湊版面測試通過。
- EXE 內嵌圖示與 16–256 像素 ICO 結構檢查通過。
