## 版本摘要

Local GitHub Library 0.2.4 集中完善“我的收藏”工作流。现在可以为收藏项目保存本地备注、集中导出备注，并通过目录行内图标完成重命名和删除；同时把本地大模型改为跨版本复用的独立发布，避免每个程序版本重复上传模型。

## 主要更新

- 收藏项目新增备注功能，可添加、查看、修改和删除，最多保存 4000 个字符。
- 可将所有非空收藏备注导出为带时间戳的 UTF-8 TXT 文件。
- 收藏备注保存在本地 `favorites.json`，会随 `.ghconfig` 配置包一起导入和导出。
- “收藏目录”标题右侧新增加号按钮，用于新建目录。
- 每个目录行新增重命名和删除图标，目录名称、仓库数量和操作图标保持居中。
- 删除目录前会显示确认提示；目录中的本地收藏项目和备注会一并删除。
- 大模型改用独立的 `models-qwen2.5-1.5b-v1` 预发布提供，程序版本不再重复上传 `.ghllm` 或完整离线包。

## 问题修复

- 修正恢复默认布局按钮与工作区标签未垂直居中的问题。
- 统一收藏目录行的目录名称、仓库数量、重命名和删除图标的垂直中心。
- 重命名图标采用无外层底板的“方框+铅笔”矢量图形，并适配浅色和深色主题。

## 兼容性与升级

- 从 0.2.3 升级不需要迁移收藏、备注、报告、Star 快照、提示词、榜单缓存或 `.ghconfig` 数据。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 删除收藏目录只影响本地数据，而且不可撤销。
- 基础搜索、榜单、收藏和报告功能不需要本地模型；需要 AI 总结与翻译时，请从独立的 LLM 模型库下载并导入模型。

## 平台与限制

- Windows 10/11 x64。
- 程序为自包含发布，不要求预装 .NET。
- 搜索、当前榜单和 README 读取需要访问 GitHub。
- 本地 LLM 为可选的独立下载，不包含在 0.2.4 标准包中。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 当前仓库尚未声明开源许可证。
