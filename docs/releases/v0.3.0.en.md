## Summary

Local GitHub Library 0.3.0 adds GitHub account sign-in and private repository search. Users can verify and save a Personal Access Token in app settings, then search public and private repositories that the signed-in account can access. The token is encrypted with Windows DPAPI for the current Windows user and is excluded from reports and `.ghconfig` exports.

## Highlights

- Add a GitHub Account section to app settings for token verification, account status, and sign-out.
- Use authenticated GitHub requests for repository search, README retrieval, and project details.
- Search private repositories accessible through the account, including organization and collaborator repositories.
- Merge an authenticated repository inventory into keyword search because GitHub's repository index can omit private repositories and private forks.
- Store the encrypted token at `GitHubReports/Data/github-auth.bin` under the current Windows user.
- Explicitly exclude login credentials from configuration exports and delete the local token on sign-out.
- Add a complete Fine-grained Personal Access Token setup guide, permission guidance, official links, and security notes to all localized READMEs.

## Fixes

- Fix private repositories not being returned when the application relied only on anonymous GitHub API requests.
- Fix private repositories being missed by keyword search when GitHub's repository index had incomplete coverage.
- Update the legacy environment-variable and `github-token.txt` guidance so new users are directed to the in-app login flow.

## Compatibility and upgrade

- Upgrading from 0.2.7 requires no migration of favorites, notes, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- `GITHUB_TOKEN` and `github-token.txt` remain available as advanced configuration fallbacks.
- Configuration imports do not contain GitHub login credentials; each computer must sign in separately.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- The local LLM remains an optional separate download and is not included in the 0.3.0 standard package.

## Platforms and limitations

- Windows 10/11 x64.
- Self-contained executable; a separate .NET installation is not required.
- Private repository search requires `Metadata` and `Contents` read-only permission for the selected repositories.
- To cover repository-index gaps, signed-in search additionally matches up to the 1,000 most recently updated accessible repositories.
- Organizations may require administrator approval for Fine-grained Tokens.
- The unsigned executable may trigger a Windows SmartScreen warning.
- The repository does not currently declare an open-source license.
