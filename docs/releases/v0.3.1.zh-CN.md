## 版本摘要

Local GitHub Library 0.3.1 改进收藏目录组织和窗口布局体验。收藏目录现在可以在左右两个目录列表中长按拖动排序，顺序会保存在本地；三个工作区的面板宽度、主窗口尺寸和最大化状态也会在关闭时保存，并在下次启动时恢复。

## 主要更新

- “查找项目”左侧目录列表和“我的收藏”目录列表均支持长按 300 ms 后拖动排序。
- 目录拖动时显示跟随鼠标的半透明虚影，并对受影响的行使用缓动动画。
- 目录顺序写入 `favorites.json` 的 `SortOrder` 字段，重启后保持。
- 单独保存“我的收藏”“查找项目”“总榜”三个工作区的左右面板宽度。
- 保存主窗口宽度、高度和最大化状态。
- 点击“恢复默认布局”会同时保存新的默认布局。

## 问题修复

- 修复上一版只给“我的收藏”页目录列表绑定拖动事件，实际“查找项目”左侧目录列表无法拖动的问题。
- 修复软件设置和关闭行为保存时可能覆盖新增布局字段的问题。

## 兼容性与升级

- 从 0.3.0 升级不需要迁移收藏、备注、报告、Star 快照、提示词、榜单缓存或 `.ghconfig` 数据。
- 旧版 `app-settings.json` 没有布局字段时会自动使用默认窗口尺寸和面板宽度。
- 配置导出会包含布局设置，但不会包含 GitHub Token。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 本地 LLM 仍是可选独立下载，不包含在 0.3.1 标准包中。

## 平台与限制

- Windows 10/11 x64。
- 窗口位置不会跨启动保存；仅保存尺寸和最大化状态。
- 面板宽度只保存左右两列，中间列保持自适应。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 当前仓库尚未声明开源许可证。

## 验证结果

- Release 构建通过，0 个警告、0 个错误。
- 两个目录列表的拖动重排、300 ms 阈值和顺序持久化测试通过。
- 三个工作区面板宽度、窗口尺寸和布局设置的加载与保存测试通过。
- 原有搜索、报告、收藏、设置、排序、托盘和紧凑布局测试通过。
