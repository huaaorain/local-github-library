# Local GitHub Library 0.2.2

0.2.2 是搜索质量与结果排序补丁，不改变收藏、报告、快照、提示词或配置包的数据格式。

## 搜索相关性

- 搜索先使用 GitHub Topics 识别领域，再用仓库名称和描述补足候选。
- 不再把 README 中的偶然提及作为主要匹配依据，减少跨领域误收录。
- 扩大名称与描述候选池，并保留 GitHub 原生最佳匹配顺序作为通用排序信号。
- 名称、描述中的直接短语匹配优先于重复的 Topic 和关键词同名信号。
- Topic 高 Star 结果用于没有直接文本匹配的领域查询，例如数据可视化。
- 名称只由查询词组成的仓库归入同一多样性类别，避免大量同名通用项目占满结果。
- 名称和描述仍不符合领域词的项目会被相关性阈值过滤。

## 排序与稳定性

- 点击 `Star` 时严格按 Star 数值降序或升序排列，不再按带千位分隔符的文本排序。
- 点击“仓库”或 `#` 时按关键词匹配顺序排列。
- 新搜索会恢复默认匹配顺序并清除旧排序箭头。
- 本地周增长计算不再覆盖搜索结果的匹配序号。

## 验证范围

发布前使用不同语言和领域的查询验证前 10 条结果，包括 Kubernetes、Rust、TensorFlow、Flutter、计算机视觉、网页抓取、数据可视化、家庭自动化、Unity、Jev、中文分词和量化交易。测试同时覆盖 Star 数值排序、仓库匹配排序、收藏、报告与布局回归。

GitHub 搜索结果会随仓库数据和搜索索引变化，具体名次可能随时间浮动；搜索实现不包含针对测试仓库的硬编码规则。

## 兼容性

- 支持 Windows 10/11 x64，程序为自包含发布，不要求预装 .NET。
- 从 0.2.1 升级不需要迁移本地数据。
- 必须保留 EXE 同级的 `runtimes` 目录。
- 标准包不包含本地模型；完整包包含 Qwen2.5 1.5B 模型，也可单独导入 `.ghllm`。
