# Local GitHub Library 0.2.0

## Summary

`v0.2.0` 是 Local GitHub Library 的第二个公开版本，重点加入可选的本地 LLM、独立的提示词管理，以及更可靠的 README 摘要和收藏体验。基础搜索、排行、收藏和报告功能不依赖模型包。

## Highlights

- 新增 `.ghllm` 本地模型扩展包，可在仓库详情中流式生成中文摘要和翻译。
- 集成 llama.cpp CPU 推理运行时，不需要 OpenAI API Key 或云端推理服务。
- 提示词独立保存，可导入、编辑、导出，并参与生成缓存。
- 改进 README 摘要，跳过多语言导航、纯分隔线导航和顶部提示块。
- “查找项目”和“我的收藏”统一使用同一份收藏目录数据。
- 优化重复收藏状态、批量收藏按钮和目录下拉框显示。

## Fixes and improvements

- 修复单文件发布版缺少 LLamaSharp CPU 原生运行库的问题。
- 发布脚本在还原或发布失败时立即停止，并检查运行时目录。
- 过滤模型复述提示词或输出格式说明的情况。
- 当前目录已有仓库时禁用重复收藏操作。
- 混合选择中只添加缺失仓库，并显示跳过数量。
- 未安装模型时继续使用 README 摘要，基础功能保持可用。

## Compatibility and upgrade notes

- 从 `v0.1.0` 升级时建议解压完整发布包，不要只替换 EXE。
- 本地 LLM 是可选项；没有 `.ghllm` 时仍可使用搜索、排行、收藏和 README 摘要。
- 必须保留 EXE 同级的 `runtimes` 目录。
- 未发现需要迁移的既有本地数据格式变更。

## Platforms

- Windows 10/11 x64
- 基础程序不要求预装 .NET 运行时
- 本地 LLM 推荐 6–8 GB 可用内存
