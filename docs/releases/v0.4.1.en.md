## Summary

Local GitHub Library 0.4.1 adds a customizable global restore shortcut, persistent table column widths, more reliable installation-specific Windows startup registration, and a clear PolyForm Noncommercial 1.0.0 license.

## Highlights

- Add a global restore shortcut, defaulting to `Ctrl+Shift+D`.
- Restore the window when it is minimized to the taskbar or system tray.
- Let users record, reset, and persist a custom shortcut in app settings.
- Persist table column widths across restarts for Search, Rankings, and Favorites.
- Use the visible table-column boundary as the resize handle, avoiding an extra divider and color mismatch.
- Scope Windows startup registration to each installation directory so different copies no longer remove each other's entries.
- Add the PolyForm Noncommercial 1.0.0 license text and include it with the standard package and standalone executable.

## Fixes

- Prevent a legacy generic startup entry from being reused by another application copy.
- Restore resized table columns after restarting the application.
- Apply shortcut changes without requiring an application restart.
- Provide a direct restore path while the window is minimized to the taskbar or tray.

## Compatibility and upgrade

- Upgrading from 0.4.0 requires no migration of reports, favorites, notes, Star snapshots, prompts, or ranking caches.
- Missing shortcut and column-width fields in older settings automatically fall back to safe defaults.
- Keep the `runtimes` directory beside the executable when replacing only the EXE.
- The local LLM remains an optional separate download and is not included in the standard package.
- The license change does not retroactively alter previously published releases; versions from 0.4.1 onward use the noncommercial license.

## Platforms and limitations

- Windows 10/11 x64.
- A global shortcut requires at least one modifier key and may conflict with a combination already used by another application.
- GitHub search and rankings require network access; favorites browsing, cached rankings, and local notes work offline.
- The unsigned executable may trigger a Windows SmartScreen warning.
- This project uses PolyForm Noncommercial 1.0.0, permits noncommercial use only, and is not an OSI open-source license. Commercial use requires separate authorization.
