# Local GitHub Library 0.1.0

## Summary

`v0.1.0` 是 Local GitHub Library 的首个公开版本，建立了 GitHub 项目发现、Star 排行、收藏整理和本地报告的基础工作流。

## Highlights

- 按关键词搜索 GitHub 仓库，并配置结果数量。
- 查看当前 Star 排行，基于同一主题的本地快照计算增长。
- 支持日、周、月、双月、半年和年的全站榜单。
- 使用收藏目录整理项目，并跳过重复条目。
- 从 README 提取项目概述。
- 将报告保存为本地 TXT 文件。
- 支持 `.ghconfig` 配置导入与导出。
- 提供自包含 Windows x64 可执行文件。

## Fixes and improvements

- 这是首个公开版本，不包含相对上一版本的修复记录。

## Compatibility and upgrade notes

- 这是首次公开发布，没有旧版本升级步骤。
- 搜索和当前榜单需要网络连接。
- 全站增长榜使用 OpenGithubs 公开日榜数据。
- 此版本不包含本地 LLM 扩展。

## Platforms

- Windows 10/11 x64
- 不要求预装 .NET 运行时
