## 版本摘要

Local GitHub Library 0.4.0 新增完整的本機筆記工作區，並把筆記儲存升級為依目錄層級組織的 Markdown 與圖片倉庫。筆記支援目錄樹、拖動排序、正文圖片、加粗、文字顏色、自動儲存、加密和右鍵操作；同時加入單一執行個體保護、原子寫入、索引備份和損壞偵測，避免再次出現索引與正文被寫壞的問題。

## 主要更新

- 在「搜尋」「總榜」「收藏」之外新增「筆記」工作區。
- 使用目錄樹整理筆記，支援建立目錄、刪除目錄和長按拖動排序。
- 每則筆記保存為同名 `.md` 檔案，相關圖片保存在同層 `images` 目錄。
- 支援正文內貼上圖片、複製原圖、Ctrl+滾輪縮放和正文內圖片持久化。
- 支援加粗、六種文字顏色及 `Ctrl+S` 儲存。
- 保留每 3 分鐘自動儲存，並在未儲存離開時詢問。
- 支援右鍵開啟、儲存、移動、刪除、建立目錄、建立筆記和「開啟方式」。
- 「開啟方式」支援預設程式、記事本、Visual Studio Code 和檔案總管。
- 加密筆記使用 PBKDF2-SHA256 + AES-GCM；加密正文和圖片分別保存為 `.md.enc` 與 `*.png.enc`。
- 刪除加密筆記時必須再次輸入正確密碼。
- `.ghconfig` 會包含一般筆記、目錄層級、圖片、加密筆記和富文字中繼資料。

## 問題修正

- 修正不同目錄深度下筆記刪除圖示參差不齊的問題。
- 修正正文貼上後字型、粗細和顏色混雜的問題。
- 修正加密筆記圖片在重新開啟後顯示為 Markdown 文字的問題。
- 修正密碼視窗底部按鈕被裁切的問題。
- 修正同目錄筆記拖動時缺少平滑讓位動畫的問題。
- 修正不同層級筆記全部堆積在最低層級目錄下方的問題。
- 新增單一執行個體限制，避免多個程式同時寫入筆記資料。
- 索引、Markdown、圖片和加密檔案改為驗證後原子寫入，並保留索引 `.bak` 備份。
- 主索引損壞時自動嘗試讀取備份；資料仍無法讀取時停止寫入並顯示明確錯誤。

## 相容性與升級

- 從 0.3.1 升級不需要重新匯入報告、收藏、備註、Star 快照、提示詞或榜單快取。
- 舊版一般筆記會在首次載入時遷移為目錄、Markdown 和圖片檔案。
- 舊版加密筆記無法在不知道密碼時讀取標題，會先建立安全佔位目錄；解鎖並保存後自動改為真實筆記名稱。
- 筆記檔案格式有較大變化。升級前建議先匯出 `.ghconfig` 或複製整個 `GitHubReports` 目錄。
- 從舊版升級時請只執行一個程式執行個體。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 本機 LLM 仍是可選獨立下載，不包含在本版本標準包中。

## 平台與限制

- Windows 10/11 x64。
- 加密筆記會保護正文與圖片內容；標題、目錄名稱和檔案數量可能仍能從本機路徑看出。
- 忘記筆記密碼後無法恢復正文。
- 筆記工作區支援離線使用；GitHub 搜尋和榜單仍需要網路。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。
