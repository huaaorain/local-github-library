## 版本摘要

Local GitHub Library 0.2.7 集中改進收藏組織和軟體設定。現在可以設定 Windows 開機自啟，在目錄清單中快速識別有備註的專案，並透過長按拖動自訂倉庫順序。拖動使用跟隨滑鼠的半透明虛影和緩動滑動動畫。進入「我的收藏」時預設顯示目錄內容。

## 主要更新

- 軟體設定新增「開機時自動啟動 Local GitHub Library」，預設關閉。
- 開機自啟使用目前使用者的 Windows `Run` 登錄項目，不需要系統管理員權限。
- 有備註的倉庫名稱前顯示可點擊的備註圖示；無備註專案不顯示。
- 長按倉庫名稱 300 ms 後進入拖動狀態，游標和拖動虛影會明確提示目前專案。
- 拖動時清單即時跨列重排，受影響的列使用 180 ms 緩動動畫平滑滑動。
- 自訂順序寫入 `favorites.json` 的 `SortOrder` 欄位，重新啟動後仍然有效。
- 新收藏專案仍顯示在目錄頂部。
- 「目錄內容」移動到「搜尋結果」之前，並成為「我的收藏」的預設頁籤。
- 執行搜尋後仍自動切換到搜尋結果頁籤。

## 問題修正

- 替換原先依賴 Windows OLE 拖放的實作，修正收藏專案完全拖不動的問題。
- 修正拖動虛影內部文字沒有跟隨卡片位置的問題。
- 修正關閉視窗設定更新時可能重置開機自啟狀態的問題。

## 相容性與升級

- 從 0.2.6 升級不需要遷移收藏、備註、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 舊收藏資料沒有 `SortOrder` 時會繼續依收藏時間顯示，首次拖動後寫入新順序。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 開機自啟只影響目前 Windows 使用者，移動程式位置後會在下次啟動時校正路徑。
- 本機 LLM 仍是可選獨立下載，不包含在 0.2.7 標準包中。

## 平台與限制

- Windows 10/11 x64。
- 程式為自包含發佈，不要求預先安裝 .NET。
- 收藏拖動僅調整目前目錄內部順序，不跨目錄移動專案。
- 搜尋、目前榜單和 README 讀取需要存取 GitHub。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。

## 驗證結果

- 開機自啟註冊、取消和設定持久化測試通過。
- 備註圖示僅對 `HasNote` 專案顯示，點擊入口與右側備註按鈕共用同一編輯流程。
- 300 ms 長按閾值、拖動虛影位置更新和即時重排測試通過。
- 180 ms 滑動動畫調度、反向重排和 `SortOrder` 持久化測試通過。
- 目錄內容優先排列、預設頁籤和搜尋結果自動切換測試通過。
- 搜尋、報告、收藏、設定、排序、托盤和緊湊版面測試通過。
