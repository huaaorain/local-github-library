## 版本摘要

Local GitHub Library 0.2.7 集中改进收藏组织和软件设置。现在可以设置 Windows 开机自启，在目录列表中快速识别有备注的项目，并通过长按拖动自定义仓库顺序。拖动使用跟随鼠标的半透明虚影和缓动滑动动画。进入“我的收藏”时默认显示目录内容。

## 主要更新

- 软件设置新增“开机时自动启动 Local GitHub Library”，默认关闭。
- 开机自启使用当前用户的 Windows `Run` 注册表项，不需要管理员权限。
- 有备注的仓库名称前显示可点击的备注图标；无备注项目不显示。
- 长按仓库名称 300 ms 后进入拖动状态，光标和拖动虚影会明确提示当前项目。
- 拖动时列表实时跨行重排，受影响的行使用 180 ms 缓动动画平滑滑动。
- 自定义顺序写入 `favorites.json` 的 `SortOrder` 字段，重新启动后仍然有效。
- 新收藏项目仍显示在目录顶部。
- “目录内容”移动到“搜索结果”之前，并成为“我的收藏”的默认页签。
- 执行搜索后仍自动切换到搜索结果页签。

## 问题修复

- 替换原先依赖 Windows OLE 拖放的实现，修复收藏项目完全拖不动的问题。
- 修复拖动虚影内部文字没有跟随卡片位置的问题。
- 修复关闭窗口设置更新时可能重置开机自启状态的问题。

## 兼容性与升级

- 从 0.2.6 升级不需要迁移收藏、备注、报告、Star 快照、提示词、榜单缓存或 `.ghconfig` 数据。
- 旧收藏数据没有 `SortOrder` 时会继续按收藏时间显示，首次拖动后写入新顺序。
- 直接替换 EXE 时，请保留同级的 `runtimes` 目录。
- 开机自启只影响当前 Windows 用户，移动程序位置后会在下次启动时校准路径。
- 本地 LLM 仍是可选独立下载，不包含在 0.2.7 标准包中。

## 平台与限制

- Windows 10/11 x64。
- 程序为自包含发布，不要求预装 .NET。
- 收藏拖动仅调整当前目录内部顺序，不跨目录移动项目。
- 搜索、当前榜单和 README 读取需要访问 GitHub。
- 未签名 EXE 可能触发 Windows SmartScreen 提示。
- 当前仓库尚未声明开源许可证。

## 验证结果

- 开机自启注册、取消和设置持久化测试通过。
- 备注图标仅对 `HasNote` 项目显示，点击入口与右侧备注按钮共用同一编辑流程。
- 300 ms 长按阈值、拖动虚影位置更新和实时重排测试通过。
- 180 ms 滑动动画调度、反向重排和 `SortOrder` 持久化测试通过。
- 目录内容优先排列、默认页签和搜索结果自动切换测试通过。
- 搜索、报告、收藏、设置、排序、托盘和紧凑布局测试通过。
