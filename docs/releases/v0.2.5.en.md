## Summary

Local GitHub Library 0.2.5 adds a central settings experience and a system-tray workflow. Common tools move out of the header, closing can minimize to the tray or exit completely, and the app can ask for a choice every time. Search, rankings, favorites, reports, and the separate model-release strategy remain unchanged.

## Highlights

- Add a header gear that centralizes LLM import, configuration import/export, and opening the local document library.
- Choose whether closing minimizes to the system tray or exits the application.
- Save a default close action in app settings and choose whether to ask every time.
- Add a “每次关闭窗口时都询问我” option to the close confirmation dialog; clearing it remembers the current choice.
- Support tray double-click to restore the main window and a context menu to reopen or exit.
- Store app settings in `GitHubReports/Data/app-settings.json` and include them in `.ghconfig` exports and imports.
- Keep only the light/dark switch and gear in the header and remove the outer rounded container around them.

## Fixes

- Fix possible overlap between the “完全退出程序” and “取消” controls in the close dialog.
- Pin the cancel control to the bottom-right and keep the action area free of overlap.
- Avoid reentrant close handling so an explicit exit closes the application reliably.

## Compatibility and upgrade

- Upgrading from 0.2.4 requires no migration of favorites, notes, reports, Star snapshots, prompts, ranking caches, or `.ghconfig` data.
- On first launch of 0.2.5, close confirmation is enabled by default and offers tray-minimize or full-exit choices.
- Keep the `runtimes` directory beside the executable when replacing only `GitHubTopicReports.exe`.
- The local LLM remains an optional separate download and is not included in the 0.2.5 standard package.

## Platforms and limitations

- Windows 10/11 x64.
- Self-contained executable; a separate .NET installation is not required.
- The tray workflow depends on the Windows notification area.
- Search, current rankings, and README reading require GitHub access.
- The unsigned executable may trigger a Windows SmartScreen warning.
- The repository does not currently declare an open-source license.
