## 版本摘要

Local GitHub Library 0.3.0 新增 GitHub 帳號登入與私有倉庫搜尋。使用者可以在軟體設定中使用 Personal Access Token 驗證並保存登入狀態，隨後搜尋目前帳號有權限存取的公開和私有倉庫。登入憑證使用 Windows DPAPI 加密，僅供目前 Windows 使用者使用，且不會寫入報告或 `.ghconfig` 設定包。

## 主要更新

- 軟體設定新增「GitHub 帳號」區域，可驗證 Token、顯示目前登入帳號並登出。
- GitHub 驗證資訊統一用於倉庫搜尋、README 讀取和專案詳情請求。
- 登入後可搜尋帳號擁有權限的私有倉庫，包括組織倉庫和協作者倉庫。
- 由於 GitHub 內建的倉庫搜尋索引可能遺漏私有倉庫或私有 Fork，程式會額外讀取帳號可存取的倉庫清單，在本機依關鍵詞匹配並去重後合併結果。
- Token 使用 Windows DPAPI 依目前使用者加密保存在 `GitHubReports/Data/github-auth.bin`。
- 設定匯出明確排除登入憑證；登出會刪除本機保存的 Token。
- 首頁新增 Fine-grained Personal Access Token 建立步驟、權限建議、官方連結和安全說明。

## 問題修正

- 修正僅使用匿名 GitHub API 時無法傳回個人私有倉庫的問題。
- 修正私有倉庫因 GitHub 搜尋索引覆蓋不足而無法透過關鍵詞找到的問題。
- 更新原有環境變數和 `github-token.txt` 相容提示，引導新使用者使用軟體內登入流程。

## 相容性與升級

- 從 0.2.7 升級不需要遷移收藏、備註、報告、Star 快照、提示詞、榜單快取或 `.ghconfig` 資料。
- 原有 `GITHUB_TOKEN` 環境變數和 `github-token.txt` 仍可作為進階設定方式使用。
- 設定檔匯入不包含 GitHub 登入憑證，每台電腦需分別登入。
- 直接替換 EXE 時，請保留同層的 `runtimes` 目錄。
- 本機 LLM 仍是可選獨立下載，不包含在 0.3.0 標準包中。

## 平台與限制

- Windows 10/11 x64。
- 程式為自包含發佈，不要求預先安裝 .NET。
- 私有倉庫搜尋需要 Token 對相應倉庫具有 `Metadata` 與 `Contents` 的唯讀權限。
- 為彌補搜尋索引遺漏，登入後額外匹配最近更新的最多 1,000 個可存取倉庫。
- 組織可能要求管理員核准 Fine-grained Token。
- 未簽署 EXE 可能觸發 Windows SmartScreen 提示。
- 目前倉庫尚未宣告開源授權。
